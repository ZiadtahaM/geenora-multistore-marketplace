# 🏪 Geenora (جينورا) - Multi-Vendor Platform

> **Geenora** is a beautifully designed, modern, right-to-left (RTL) landing page for an Arabic multi-vendor e-commerce platform. It emphasizes smooth animations, gradient styling, and an intuitive user experience.

---

## ✨ Features

- **Modern & Vibrant Design**: Uses a highly curated color palette featuring warm gradients (oranges, pinks, yellows) that invoke trust and excitement.
- **Micro-interactions**: Hover effects, floating badges, and smooth scaling on elements to create a dynamic and alive UI.
- **RTL Built-in**: Architected from the ground up to support Right-to-Left languages natively, perfect for the MENA region.
- **Fully Responsive**: Optimized for desktops, tablets, and mobile devices using CSS Grid and Flexbox.
- **Modular Architecture**: Clean separation of concerns with isolated HTML, CSS, and JavaScript files.
- **Vanilla Tech Stack**: Built without heavy frameworks for ultimate performance, relying purely on HTML5, CSS3, and ES6 JavaScript.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic tags for better SEO and accessibility.
- **CSS3**: Advanced properties including Flexbox, CSS Grid, custom keyframe animations (`@keyframes float`), and backdrop-filters (Glassmorphism).
- **JavaScript (ES6)**: Lightweight DOM manipulation for header scroll effects and interactive UI elements.
- **Fonts**: [Cairo](https://fonts.google.com/specimen/Cairo) from Google Fonts for beautiful Arabic typography.

## 🚀 How to Run Locally

You don't need any complex build tools to run this project! 
Just follow these simple steps:

1. Clone or download this repository.
2. Open the folder in your terminal.
3. Start a local server:
   - Using Python: `python -m http.server 8080`
   - Using Node.js: `npx http-server`
4. Visit `http://localhost:8080` in your web browser.

*(Alternatively, you can just double-click `index.html` to view it locally).*

## 🧑‍💻 Developer Notes (The Enhancement Process)

This project was enhanced from a single static prototype file into a production-ready template. 
Key improvements include:
1. **Separation of Concerns**: Extracted embedded `<style>` tags into a dedicated `styles.css` file.
2. **Added Interactivity**: Introduced a `script.js` file to handle scroll events, sticky navigation shadow effects, and button interactivity.
3. **SEO & Semantics**: Improved the underlying HTML structure for better screen-reader accessibility and SEO.
4. **Code Documentation**: Extensively commented the CSS and JS to make it easy to maintain and scale.
